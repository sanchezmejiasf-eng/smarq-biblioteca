# SMARQ Biblioteca

Simuladores 3D y objetos GDL de maquinaria para Archicad 27.

- **Catálogo:** https://sanchezmejiasf-eng.github.io/smarq-biblioteca/
- **Objetos GDL:** en [Releases](https://github.com/sanchezmejiasf-eng/smarq-biblioteca/releases)

## Usar en Archicad
1. Descarga el `.gsm` y guárdalo en una carpeta.
2. Archivo > Bibliotecas y objetos > Gestor de bibliotecas > Añadir.
3. Con la herramienta Objeto, busca "Komatsu".

Incluyen posiciones de trabajo, separación entre partes, nivel de detalle y representación en planta. Ejes: X al frente, Y a la izquierda del operador, Z = 0 en el suelo.
